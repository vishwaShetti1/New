============================================================
SQL JOIN vs Pandas Merge Comparison Report
============================================================

Project:
Data Pipeline using Web Scraping, SQLite, SQL and Pandas

Objective:
To verify that the SQL JOIN result and the pandas merge() result
produce the same output.

------------------------------------------------------------
Tables Used
------------------------------------------------------------

1. books
2. categories

Join Condition:

books.category_id = categories.category_id

------------------------------------------------------------
SQL Method
------------------------------------------------------------

The SQL JOIN was executed using:

SELECT
    b.title,
    c.category_name,
    b.rating,
    b.price_gbp,
    b.price_inr,
    b.in_stock
FROM books b
INNER JOIN categories c
ON b.category_id = c.category_id;

------------------------------------------------------------
Pandas Method
------------------------------------------------------------

The same result was obtained using:

pd.merge(
    books_df,
    categories_df,
    on="category_id",
    how="inner"
)

------------------------------------------------------------
Comparison Result
------------------------------------------------------------

Both outputs contain the same columns.

Both outputs contain the same records.

The rows are sorted before comparison.

Comparison Result:

True

------------------------------------------------------------
Conclusion
------------------------------------------------------------

The SQL INNER JOIN and pandas merge() produce identical results,
confirming that the database and DataFrame operations are consistent.
